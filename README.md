# UserLink

Portal de RH para funcionários. Desenhei as telas no Figma e implementei as principais em HTML, CSS e JavaScript.

**Design:** https://www.figma.com/proto/bcHxcBD5Mp3seldmzFYHRb/Cadastro-de-Usu%C3%A1rios?node-id=806-34018&p=f&viewport=831%2C223%2C0.13&t=Biaj4KImcAFfEgKl-1&scaling=contain&content-scaling=fixed&starting-point-node-id=797%3A33901&page-id=68%3A2

Tem login e cadastro, perfil, relatórios, pagamento e ajuda, com tema claro e escuro. Os dados são fictícios e não há servidor.

Para rodar, abra o `index.html` no navegador.

Fora do protótipo: foto de perfil, envio real de anexos e integração com uma API.
